# Echoes of Eternity - Sacred India Explorer

A college project website showcasing 12 sacred and natural tourist places in India.

## Features
- Login / Register system
- Admin dashboard
- Search and filter tourist places
- Detailed pages for each place
- Google Maps directions and route links
- Responsive design

## Tech Stack
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Setup
1. Clone the repo.
2. Copy `includes/db_connect.sample.php` to `includes/db_connect.php`.
3. Update DB credentials.
4. Import `database/echoes_of_eternity.sql` into MySQL.
5. Run with XAMPP / WAMP / LAMP.

## Note
GitHub Pages does not run PHP. Use a PHP host or run locally with XAMPP.
